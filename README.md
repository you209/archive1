# Bargain Bloom Android
Standalone Android 8+ app. Photos, current public Shopify product prices, search, favourites, price caps, 12-hour periodic scans, and price-drop alerts.

This build is isolated on a dedicated branch of the public archive1 repository; main is unchanged.

Build: Gradle 8.10.2, JDK 17, Android SDK 35. GitHub Actions produces a downloadable **Bargain-Bloom-Android-APK** artifact.

Initial test stores: Dangerfield, Princess Highway and Beserk. Feeds are not guaranteed to work; scan errors are displayed. Always verify sizes and checkout total on retailers' websites. This is a debug-signed APK, not a Play Store release.
